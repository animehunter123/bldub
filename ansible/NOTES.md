# **Homelab Ubuntu Opener — Ansible Automation**

This project sets up a **fully open homelab configuration** for Ubuntu servers using Ansible.
It includes:

* Simple inventory
* A playbook that applies a role called `open`
* A role that disables UFW, loosens SSH security, installs tooling, and configures system settings
* A bootstrap script that generated this entire structure

It is designed for **two Ubuntu servers**, but works with any number.

## 🧩 What the Playbook Does

Running `open.yml` applies the `open` role, which:

### 🔓 Security Relaxation (homelab-friendly)

* Disables UFW
* Enables SSH password authentication
* Enables root SSH login
* Restarts SSH when needed

### 🛠️ Installs common tools

* htop
* curl
* wget
* git
* vim
* net-tools
* iputils-ping

### 🌐 Networking improvements

* Enables IPv4 packet forwarding

### 📈 System Tweaks

* Raises open file limits
* Ensures systemd-timesyncd is enabled

This ensures Ansible finds the correct roles and inventory:

```ini

```

## 🚀 Running the Playbook

From inside the project directory:

### If your SSH user *has* passwordless sudo:

```bash
ansible-playbook playbooks/open.yml
```

### If your SSH user *requires* a sudo password:

```bash
ansible-playbook playbooks/open.yml --ask-become-pass
```

## 🧯 Troubleshooting

### “sudo: interactive authentication is required”

Add passwordless sudo:

```
sudo visudo
lmadmin ALL=(ALL) NOPASSWD: ALL
```

### “role 'open' not found”

Make sure `ansible.cfg` exists with:

```
roles_path = ./roles
```
